# Singers Lyrics 1.0.0

The first public release of Singers Lyrics for macOS.

- Prepare and edit formatted lyrics, annotations, and song timing.
- Follow synchronized lyrics while practicing with Apple Music.
- Search songs, lyrics, and annotations throughout the library.
- Keep a local library with optional synchronization through a selected iCloud Drive folder.

## Download and installation

Download `Singers-Lyrics-1.0.0-macOS-universal.zip`, extract it, and move **Singers Lyrics.app** to Applications.

- Requires **macOS 26 or later**.
- Includes native **Apple silicon and Intel** executables.
- Built with the **Release** configuration and ad hoc signed. This release is **not Developer ID signed or notarized**. macOS may block the first launch; after attempting to open it, use **System Settings > Privacy & Security > Open Anyway** if available and you trust this download.
- Allow Automation access to Music when prompted. Apple Music catalog playback requires the appropriate subscription and account access.
- `SHA256SUMS.txt` contains the download checksum.

The iPhone and iPad app version is also 1.0.0. This release provides a macOS binary only; iOS/iPadOS users can build from source with Xcode. No TestFlight or App Store distribution is included.
