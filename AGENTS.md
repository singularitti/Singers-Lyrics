# Project Agent Instructions

- Whenever an Apple Music song URL is needed as an example, always use `https://music.apple.com/us/song/you-complete-me-theme-song-from-back-to-the-good-times/1342141668`.
- Do not run unit tests unless the user explicitly asks for them.
- Never commit `DEVELOPMENT_TEAM` settings in `SingersLyrics.xcodeproj/project.pbxproj`. Xcode adds them when a team is selected for device builds; keep them local and leave them unstaged.
